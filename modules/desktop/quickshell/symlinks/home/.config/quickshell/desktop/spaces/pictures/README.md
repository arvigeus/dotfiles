# Pictures

Fullscreen wallpaper discovery from Wallhaven, Bing Daily and your configured
providers, with favorites, filters, a grid or strip, and full-image previews.
Wallhaven defaults to SFW. Bing searches its recent daily-image window.

Applying an image updates every desktop display and the lock screen. The choice
survives closing Pictures and shell restarts. **Displays → Random Wallhaven
wallpaper** applies a random SFW image without opening Pictures.

Private provider settings live in
`~/.config/quickshell/desktop/spaces/pictures/pictures.json`. Existing Games Steam
credentials also enable Wallpaper Engine Workshop browsing. Steam handles
subscriptions/downloads; Wallpaper Engine and Proton must be installed in Steam.
Wallpiper playback remains experimental. Video providers use silent looping
MP4 playback and a still frame on the lock screen.

After reinstalling, apply a wallpaper again. External media/Steam libraries need
their own backup or mounts.

See [architecture and provider configuration](ARCHITECTURE.md).
