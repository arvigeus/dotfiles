# Television

Browse public IPTV channels with country, language and category filters, local
favorites, and alternate streams/qualities. Enter or Play opens your normal mpv
window and hides the browser. Closing Television from Spaces also stops its
player; hiding Television preserves playback.

Playback uses your existing mpv controls and configuration. Some channels are
region restricted or off-air; try another stream when available. Favorites and
the saved channel directory remain available offline, but watching needs a
connection. Refresh updates the directory. No account or Nextcloud setup is needed.

Channel data comes from [IPTV-org](https://github.com/iptv-org/iptv). See
[architecture](ARCHITECTURE.md) for playback, storage and validation details.
