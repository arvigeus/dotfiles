# Radio

Browse Radio Browser stations by name, country and genre, save favorites, and
choose between a station's stream qualities. Playback continues while Radio is
hidden; closing it from Spaces stops playback.
The Sound drawer also offers playback controls while Radio is hidden.

Enter plays the selected station. Space pauses or resumes playback. Favorites
and previous search results remain available offline; streams still need a
connection. Listening needs no account.

Favorites also sync with Nextcloud Music using the shared Nextcloud account.
Matched stations show catalogue names, metadata and quality choices; unmatched
streams remain usable as custom favorites. Sync runs on opening/returning, after
favorite changes, and every minute while visible. Refresh also syncs favorites;
offline changes retry when you return.

See [architecture](ARCHITECTURE.md) for storage, restore and validation details.
