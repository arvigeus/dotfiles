# Interface icons

The interface SVGs are from [Lucide](https://github.com/lucide-icons/lucide), revision
`440a1e1dfb1e712505308da46bead3c28b1f1398`, copied without modification from `icons/`.
The complete upstream ISC/MIT notice is in [LICENSE](LICENSE).

Add individual SVGs as the interface needs them and retain their license notices.
`ui/Icon.qml` tints monochrome interface icons with Qt Quick. Application artwork
uses `ui/AppIcon.qml` and the system icon theme.

`cloudflare.svg` is provider artwork from [Simple Icons](https://simpleicons.org/?q=cloudflare),
distributed under CC0. It uses a `currentColor` fill for theme tinting. Cloudflare
trademarks belong to their respective owners.
