# qBittorrent

[Upstream](https://www.qbittorrent.org/)

Installs the native client with search enabled and a local Web UI at
[127.0.0.1:8080](http://127.0.0.1:8080). Local clients, including Movies,
connect without credentials. Other machines cannot connect.

Close qBittorrent before applying configuration. The Web UI runs while the
client is open. Search plugins are configured separately in the private repo.

See [ARCHITECTURE.md](ARCHITECTURE.md) for configuration details.
