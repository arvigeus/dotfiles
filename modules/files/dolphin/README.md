# Dolphin

Single-click opening, archive browsing and HEIC/HEIF previews are enabled.
Custom file workflows appear under **Open with**:

- [PDF tools](../../media/tools/pdf/README.md): pages, passwords and batch processing.
- [File tools](../tools/general/README.md): rename previews, checksums, links and discovery.
- [Encryption tools](../tools/encryption/README.md): OpenPGP encryption, signatures and keys.
- [Audio tools](../../media/tools/audio/README.md) and
  [Video tools](../../media/tools/video/README.md): inspection, tags and conversion.
- [Project tools](../../dev/tools/projects/README.md): folder tasks and Git maintenance.

[gImageReader](../../media/tools/ocr/README.md) handles image/PDF text recognition.
**Share → Add to Assistant** accumulates selected local files in the
[Assistant draft](../../desktop/quickshell/README.md#assistant) without opening it.
The embedded terminal requires Konsole; the separate terminal action uses Kitty.

See [ARCHITECTURE.md](ARCHITECTURE.md) for integration details.
